# Compose 发布生命周期原型验收

日期：2026-10-15。范围为实施计划 T1，仅更新独立 HTML 原型；不代表生产发布、迁移或恢复能力已经接入。

## 页面与使用路径

打开同目录的 `index.html`，从页尾“演示场景”选择预设。顶部共用部署位置与当前版本，内容通过“发布版本 / 部署历史”两个 Tab 分离；默认打开发布版本，左侧发布影响、右侧检查、底部确认操作。数据库、数据处理、配置网络和依赖按需展开。

正常路径为选择版本 → 运行检查 → 预览发布 → 确认 → 查看阶段结果。数据库目标在“部署设置”中单独绑定。修改版本、目标或迁移草稿后，原检查与确认失效。

## 十类场景

| 场景 | 验证结果 |
| --- | --- |
| 无数据库变更 | 显示迁移清单与启动行为的示例依据，不创建迁移执行阶段 |
| 兼容新增字段 | 扩展迁移完成后部署应用；回退恢复应用与配置，保留新增结构和业务数据 |
| 删除字段 | 旧 worker 与报表依赖未退出时阻断；兼容性和恢复能力不显示通过 |
| 证据缺失 | 不把未取得迁移清单视为无变更；检查和兼容结论保持未核对 |
| 历史 checksum 漂移 | 阻断发布，不自动修正已执行历史或跳过迁移 |
| 迁移成功、应用失败 | 保留迁移完成及应用验证失败事实；核对停止后重新检查、确认独立应用回退 |
| 迁移结果未知 | 停止后续阶段，观察与刷新保持未知及占用，不提供直接重试或解锁 |
| 回填部分完成 | 暂停于 4,000 / 10,000 行；核对游标后单独确认续跑，校验完成才切换读取 |
| 秘密引用失效 | 保留归档也不能恢复失效凭据；阻断执行，恢复能力显示有条件 |
| 旧版数据语义不兼容 | 即使表结构相同，旧应用不认识新业务状态时也阻断回退 |

## 恢复与协作合同

- 应用回退、迁移向前修复、数据恢复分别解释，不提供隐式数据库降级或恢复卷操作。
- 续跑记录明确标记此前已完成阶段为引用证据，展示新确认的起始游标，不重放迁移或部署。
- 多次恢复成功后沿父运行链关联恢复结果，保留祖先原始失败和暂停事实；刷新不会重新占用旧失败运行。
- 部分回填后恢复应用，再次发布仍包含剩余回填与数据校验；结构已扩展不能代表数据处理完成。回填全部完成但校验未完成时仍须校验。
- Agent 只展示绑定候选或运行证据的模拟建议；不修改检查结论，不解除未知占用，不触发真实模型请求。审计入口沿用程序既有模块。

## 验证证据

真实 Chrome / Playwright 共 47 项交互检查通过，包含原有发布、历史、地址设置、Agent、过期确认和键盘焦点回归，以及生命周期场景和新增 Tabs 交互。切换页签保留候选、有效检查和展开详情；在历史页等待运行完成不会中断执行或强制切回发布。历史回退返回发布页重新检查，方向键与 Home/End 切换正确，弹窗返回焦点可达。四种宽度为 1360、820、605、390px，覆盖深浅主题、展开影响区及迁移弹层，无页面横向溢出，窄屏检查区位于影响区之后。

独立只读复核关闭三项发现：阻断时错误显示可回退、多次恢复后的旧占用复活、部分回填后再次发布遗漏数据处理。原脚本 VM 另外核对 100 个场景/版本/数据库组合，以及回填完成但未校验分支；这部分证据与真实浏览器检查分别计算。

本机验收脚本：`/private/tmp/dutydeck-compose-lifecycle-regression.py`。结果与截图：`/private/tmp/dutydeck-compose-tabs-review/`。上述目录是临时验证产物，不是项目运行依赖。部分场景使用浏览器虚拟时钟推进，因此截图时间不是生产观测时间。

从最终 HTML 提取内联 JavaScript 的 Bun 构建与 Git 差异格式检查通过。浏览器验收无脚本错误、无 HTTP/HTTPS 请求；页面没有真实 SSH、SQL 或部署通道。本轮不以生产应用类型检查或数据库集成测试作为通过声明。

## 影响与后续边界

仅独立原型、验收记录和计划进度发生变化，无新增依赖或后台轮询。阶段使用单个计时器串行模拟，浏览器本地保存示例历史；不增加运维、Agent 或审计生产模块的运行开销。

T1 完成不等于 P0 完成。T2 仍需确认首个真实目标项目、迁移框架、数据库身份和恢复资产；正式执行路径继续按已批准计划的后续阶段推进。
