# 交互设计 V3：分组页面悬浮目录

日期：2026-10-14。状态：可点击评审稿的设计说明，非已接入 DutyDeck 的产品功能。

本文已同步本轮用户确认的目录覆盖和按钮去重规则。正式功能、Agent 与存储规划见[模块对齐计划](../plans/2026-10-14-interaction-design-alignment.md)。

## 结论

V3 保留 V2 的“主会话 + 单页体验优先”，把页面导航从底部步骤条移到工作区左侧的分组页面悬浮目录。目录采用 DutyDeck 项目管理侧栏已有的排序、折叠、重命名和移动语义，但在工作区内覆盖展示，开关不改变预览位置、尺寸或缩放。流程检查统一进入页头“交互流程”，不再在底部重复提供入口。

## 为什么调整

底部步骤条适合表达一条短流程，无法承载持续增长的页面集合。页面的目录顺序、页面间的跳转关系和用户本次实际访问路径是三个不同对象，混在底部会让用户误以为页面顺序就是流程顺序。

V3 将三者分开：

- 页面侧栏负责发现、分组、排序和切换页面。
- 交互流程视图负责编辑页面之间的连接。
- 体验记录负责说明本次实际点击走过的路径。

## 侧栏结构

工作区以主会话和单页预览为主体，页面目录在所有宽度下都是覆盖层，选页后收起；外部点击不穿透，Escape 逐层关闭菜单和目录。原型内部仅有一个模块标识的右栏及其占位已删除。正式应用自身的全局工作区工具栏继续负责导航，不属于本次删除范围。

页头集中“页面、版本记录、交互流程、导出”；预览工具栏保留“体验/选择修改、手机/桌面、重新体验、专注”。主会话中的原型卡片只定位预览，不重置进度；专注有明确退出按钮，退出恢复进入前的会话显隐。原型对比是评审工具，不纳入正式模块菜单。

页面目录包含：

- 搜索页面；
- 新建页面、新建分组；
- 分组展开/收起与页面数量；
- 页面拖拽排序和跨分组移动；
- 分组重命名、删除；
- 页面重命名、复制、删除；
- 入口页标记、当前页面选中态和页面状态徽标。

删除分组前必须先把页面移动到其他分组；入口页删除前必须先指定新的入口页。正式实现时分组和页面都使用稳定 ID，排序与折叠状态持久化。

页面行的“•••”展开就地浮动菜单，包含复制、重命名、移动到、设为入口、删除；“移动到”展开分组子菜单。菜单覆盖内容，不推动目录行和预览布局。

## Agent 边界

Agent 可以根据需求建议页面分组、发现孤立页面、指出不可达连接，但不能静默重排用户目录。分组调整应作为候选变更，携带原分组、目标分组和页面 ID，用户采纳后才生效。主会话继续作为唯一 Agent 对话入口，选中页面或元素后将 `groupId/pageId/elementId/revision` 注入上下文。

## V2 与 V3

| 关注点 | V2 | V3 |
| --- | --- | --- |
| 页面导航 | 底部步骤条 | 工作区内分组悬浮目录 |
| 页面数量 | 适合少量页面 | 支持持续增长 |
| 排序 | 仅示例顺序 | 侧栏拖拽排序、跨组移动 |
| 分组 | 无 | 创建、折叠、重命名、删除 |
| 流程 | 辅助弹窗 | 与页面目录独立 |
| 预览 | 单页体验 | 单页体验，页面由侧栏切换 |

V2 保留作为体验优先的对照稿，不修改其文件和缓存。V3 的预览产品仍沿用拾光示例，便于只比较信息架构变化。

## 性能和关联模块

V3 只运行一个活动页面，目录支持搜索，缩略图和流程图按需打开；正式实现根据几十至上百页的测量结果决定是否启用虚拟列表。正式集成复用当前主题变量、Jotai 状态和 Radix/shadcn primitives，不把页面跳转写入 Canvas 素材生产关系。Canvas、主会话和 Agent runtime 在本轮不改动。

## 评审边界

本轮原型实现真实的侧栏分组、折叠、搜索、页面排序、跨组移动、重命名、新建、删除保护、页面预览切换、V2 的局部编辑、候选采纳、版本保护和离线导出。Agent 生成仍是文案/配色预设模拟；不接真实模型、后端、账号或项目业务数据。
