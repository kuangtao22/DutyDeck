# 知识库与记忆独立交互落地

用户已确认 `docs/prototypes/2026-10-08-knowledge-memory.html`：顶部「知识库 / 记忆」Tabs；知识库保留目录＋正文，记忆使用列表＋详情；所有 Agent 操作沿用现有对话。

本修订取代此前项目知识文件计划中“知识库确认后将记忆转为只读”的约定。知识库存放结构化项目资料；记忆保存协作偏好、纠正、经验和决策背景。两者按需引用，不能因知识库确认、暂停或异常而停用记忆。

## 执行范围

1. 回归锁定知识库批准后记忆工具、画像与历史复查仍可用；保留计划模式、会话来源和工作区权限边界。
2. 用既有 Radix Tabs 实现顶部切换，来源资料保留二级入口。切换保留记忆编辑状态，记忆变更通知直接到达记忆页。
3. 记忆文件以列表呈现，详情继续使用原 Markdown 编辑器与自动保存、基线冲突检查、文件定位及 Diff；画像与历史会话授权保留。
4. 修正 Agent 提示词与默认知识维护 Skill，使职责及授权一致。
5. 运行相关 Bun 回归、真实组件隔离交互检查、单轮工作区类型检查及 Electron 构建。

## 关联影响与性能

- 不迁移或删除原记忆和知识文件，不新增数据库、IPC 或依赖。
- 不增加自动模型调用；历史会话补证据仍由用户明确授权范围。
- 记忆页首次打开后保留组件状态，避免 Tab 切换丢失冲突草稿；只读取目录及所选文件，正文搜索仍防抖且限制候选数。
- 保留知识库原扫描、提案确认、大纲、暂停恢复及来源校验流程。

## 验收

- 顶部始终有知识库与记忆两个可键盘切换的 Tabs，没有单独聊天页。
- 知识库未建立、已确认、暂停和异常均可进入记忆编辑。
- 自动保存、外部冲突保护、画像授权、历史授权及记忆 Diff 导航持续有效。
- 测试仅使用隔离夹具；模型提炼质量及真实项目内容不以隔离 UI 验证代替。

## 已完成实现与检查（2026-10-08）

- 顶部 Tabs、来源二级入口、记忆列表与详情、窄侧栏逐层浏览已接入正式组件；两种布局均使用原生容器查询，避免依赖项目未安装的 Tailwind 容器查询插件。
