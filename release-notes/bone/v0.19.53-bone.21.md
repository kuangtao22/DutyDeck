## 更新内容

### 内置本地模型与按需推理环境

- 新增 DutyDeck 内置本地模型能力：用户可在设置的可选环境能力中按需安装并校验 llama.cpp 运行环境，再下载 GGUF 模型。
- 模型下载、校验、加载、测试和启用状态统一在模型配置页管理；同一推理环境可供多个本地模型复用，未就绪时不会误启动模型。
- 本地运行时由主进程受控调度，模型能力探测、测试证据、租约和停止释放保持隔离；Ollama 继续作为独立外部供应商，由 Ollama 管理自己的模型文件。

### 编排工厂与会话状态

- 增强编排工厂失败诊断、定点补评、调用预算和重试边界，保留原始运行证据并限制补评消费。
- 会话失败状态在侧栏、标签页和折叠栏统一显示，重新运行成功后恢复正常状态。

### 数据目录迁移

- 默认用户级数据目录从 `~/.proma` 迁移为 `~/.DutyDeck`，使用独立 locator 并只读兼容旧 Proma 定位信息。
- 首次升级先创建可恢复迁移计划；目标已有部分副本、文件或符号链接时，取消操作会保留源目录和迁移记录，避免把不完整副本当作正式数据根。

### 实验资料与验证

- 补充小说角色提取真实样本、来源审计、预算提案和验证资料，冻结原始来源字节以保持哈希和切片证据。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `21`；推送标签后由 GitHub Actions 构建 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 现有旧 `~/.proma` 数据不会在后台直接复制；首次启动会在满足身份证明时展示迁移计划，由用户在迁移窗口中继续或处理冲突。
- llama.cpp 引擎和 GGUF 权重按需下载，不随安装包预置；首次使用本地模型需要网络、磁盘空间和可用硬件，真实模型性能取决于设备资源。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
