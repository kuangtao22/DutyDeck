## 更新内容

### 数据库与 Redis 写入确认

- SQL 工作台移除手工「写模式」切换，只保留只读 `SELECT` 查询和查询历史回填。
- Agent 发起数据库或 Redis 写入时，使用原生逐次确认卡展示当前目标、完整 SQL/命令和中文风险提示。
- 用户批准后会再次核对连接身份、目标库、SQL/命令和配置指纹；审批期间目标发生变化时拒绝执行，避免把确认误用到新目标。
- 完全自动模式与计划模式仍不能绕过写入确认或执行写入。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `17`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 会话、工作区、配置和 Skills 仍保存在 `~/.proma/`，本版本不迁移现有数据目录。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
