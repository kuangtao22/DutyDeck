## 更新内容

### 交互设计

- 新增项目级交互设计模块，一个项目对应一个模块，页面支持多级分组、排序、重命名和移动。
- 支持通过 Agent 创建与修改可点击原型；直接描述需要还原的项目页面，Agent 可按需读取源码、主题和资源生成候选设计稿。
- 新增固定版本的开发交接包，携带页面、视口、交互与资源信息，帮助后续 App 开发对齐设计。
- 版本入口移至预览工具栏，支持恢复和删除历史版本；保护当前版本及运行任务、开发交接引用的版本。
- 修复页面与分组菜单遮挡，统一默认模块名称及新建入口。

### 数据迁移与附件

- 完善旧默认数据目录迁移检测、确认窗口和设置页迁移入口。
- 受管附件和工作区路径改用可移植引用，迁移后按当前数据根解析，兼容历史附件路径。
- 修复迁移后图片缩略图、附件读取和 Agent 恢复时的旧路径问题；保留外部项目路径与历史会话原始记录。

### 画布与知识库

- 画布图片生成结果可回填原卡片，显示配置、运行、失败和候选状态，并处理重复或迟到结果。
- 知识库补充由当前 Agent 按任务选择扫描、导入与整理步骤；旧资料导入保留正文、附件、链接和来源信息。

### 本地模型与服务器运维

- 本地模型引擎及 GGUF 下载支持应用代理，完善失败诊断和取消安装。
- 新增独立 SSH 运维任务与终端展示，完善任务状态、输出与资源清理。
- 完善 Agent 文件修改统计，减少受管路径和历史恢复对结果展示的影响。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `26`。
- 本版本包含已合并到 `main` 的功能与修复；Compose 部署页面仍为设计原型，尚未作为生产部署功能提供。
