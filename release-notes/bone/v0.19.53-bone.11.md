## 更新内容

### Pi Agent 运行时升级

- 升级 Pi Agent Runtime 至 `0.87.1`，保留 Proma 的会话投影、项目指令、工具结果校验和费用统计边界。
- 修复运行时恢复、工具结果跨进程传递及模型能力注册的兼容问题，减少会话续接和长响应中的数据丢失风险。

### Canvas 交付与完成状态

- 收紧 Canvas 证据交付格式，区分证据引用和文本响应，避免模型把说明文字混入证据提交而导致整次交付被错误拒绝。
- 完成状态会透传运行时终止原因，交付校验未通过时显示明确的阻断状态，不再把它误报成普通运行错误。

### 编排工厂历史菜单

- 修复右侧工作区标题栏中的「历史」菜单点击后不可见的问题。
- 历史列表增加滚动高度限制并提升菜单层级，长记录不会把菜单定位到窗口外，也不会遮挡其它工作区内容。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `11`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 本版本包含 Pi 运行时兼容性调整。首次升级前建议保留现有 `~/.proma` 会话目录备份；旧会话可以继续读取和续写，但降级回旧版本前应先备份。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
