## 更新内容

### Agent 运行时与模型兼容

- 升级 Pi Agent Runtime 至 `0.99.1`，修复空会话 artifact 边界、工具结果恢复和模型目录兼容问题。
- 修复中文长上下文的输出预算估算，避免服务端因上下文总量超限拒绝请求。
- 适配 GPT-6.1 Sol 的 Responses API、272K 上下文和 Codex Fast Mode。

### 运维 Agent 权限

- SSH 与 Redis 的 Agent 只读授权持久保存，应用重启或连接断开后不会无故到期。
- 授权仍绑定会话与连接身份，显式撤销、会话删除、资源删除或身份变化时自动收回。
- 数据库继续按“未禁用表默认可读”工作，运维读写模式和禁用表规则保持不变。

### 工作区与系统运行

- 右侧工作区加号菜单改为独立透明浮层，网页保持可见，并复用应用主题、图标和菜单交互。
- 通用设置新增防止系统睡眠开关；它与飞书实时同步共同管理系统电源锁，允许息屏但保持后台任务运行。
- 优化编排工厂、浏览器菜单和 Canvas 相关交互，并补充对应回归测试。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `12`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 本版本包含 Pi 运行时和权限持久化调整。升级前建议保留现有 `~/.proma` 会话目录备份；旧会话可以继续读取和续写，但降级前应先备份。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自本仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/Proma.app`。
