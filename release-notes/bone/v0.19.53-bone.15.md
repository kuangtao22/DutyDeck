## 更新内容

### 项目知识库与记忆

- 新增项目知识库，支持来源扫描、受控检索、证据追踪、文档大纲和用户确认后的整理。
- 将项目结构化知识与协作记忆分开管理，支持当前 Agent 按 Skill 维护知识，避免后台另起模型任务。
- 增加项目知识库 IPC、Agent 工具、知识维护面板和工作区记忆预览，并保留来源版本与可撤销操作。

### 模型思考能力与请求参数

- 根据模型能力目录补全思考档位、上下文窗口、输出上限、温度和费用信息。
- 让 OpenAI、Anthropic、Google 及兼容供应商适配器按模型能力编译 reasoning effort、token budget 和 max tokens。
- Chat 思考控件与 Pi runtime 共用供应商和模型能力约束，未知模型不再借用其他供应商的思考协议。

### 编排工厂与运维体验

- 编排工厂支持流程块和评审块逐项独立采纳，并完善审批、版本和测试证据校验。
- 修正工作区菜单、Markdown 编辑器、文件变更路径和运维授权的边界行为。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `15`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 会话、工作区、配置和 Skills 仍保存在 `~/.proma/`，本版本不迁移现有数据目录。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
