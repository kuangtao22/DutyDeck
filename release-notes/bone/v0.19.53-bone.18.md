## 更新内容

### Agent 数据库写入确认扩展

- 保持 SQL 工作台只读，移除手工「写模式」切换；数据库和 Redis 写入统一由 Agent 原生逐次确认卡处理。
- 支持在已连接 SSH 主机上的 SQLite 文件执行受控写入；审批卡展示中文目标、完整 SQL 和风险提示，执行前复核连接身份、目标文件与 SQL 指纹。
- 远程 SQLite 写入使用单次事务和有界超时，提交、回滚、锁定、取消及状态未知均返回明确结果；连接中断不会自动重试。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `18`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 会话、工作区、配置和 Skills 仍保存在 `~/.proma/`，本版本不迁移现有数据目录。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
