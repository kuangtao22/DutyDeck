## 更新内容

### 媒体模型与 Agent 调用统一

- 在 Agent 输入框输入 `/`，可与 Skill 一起选择已配置、已启用且执行器支持的图片、音频和视频模型；选中后继续输入生成要求即可发送。
- 媒体模型引用在普通发送和排队消息中保持一致，Agent 可列出模型、准备生成、执行、查询、等待及取消任务。
- 图片接入 OpenAI Images 与 MiniMax Image，语音接入小米 TTS 与 MiniMax Speech，视频接入 MiniMax；生成产物统一登记到媒体资产目录。
- 模型引用仅携带模型身份，凭据在主进程按需解析；执行前会重新校验模型可用性和会话权限。

### 运维工作台

- SQL 面板支持 MySQL、PostgreSQL 与 SQLite 写入，并在操作前展示目标与 SQL 供确认；失败、取消及提交结果未知时保留明确状态。
- 运维服务器、数据库连接、数据库和表可直接引用到 Agent 会话，减少手工复制目标信息。
- 统一服务器和数据库详情头部导航，支持切换当前项目中的连接。

### 编排工厂与知识库

- 完善编排工厂的样本分组、评分、调用预算和实验记录，支持独立选择执行模型与评审模型。
- 恢复知识库目录与正文双栏，整理提案使用独立弹窗，并改善右侧面板拖拽入口。

### 文件预览

- 修复右侧 HTML 多文件预览，支持加载相对资源、刷新和重新打开，并保留源码查看入口。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `20`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 会话、工作区、配置和 Skills 仍保存在 `~/.proma/`，本版本不迁移现有数据目录。
- 媒体模型菜单只展示当前统一执行器支持的模型；即梦 CLI 与 ComfyUI 继续使用原入口。取消 MiniMax 视频当前只停止本地等待，远端生成任务可能继续运行。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
