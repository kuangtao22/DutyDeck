## 更新内容

### Windows 画布创建与恢复

- 收窄画布事务目录的权限请求，修复因索取不必要的目录权限导致创建失败的问题，并补充失败阶段诊断。
- 修复创建操作留下待确认回执后，恢复入口仍被对账检查拦截的问题。恢复会核验原操作的实际提交状态，避免重复创建；结果不确定时保留回执供继续恢复。

### 画布 Agent 能力

- 普通项目 Agent 可管理整图生命周期，包括列出、重命名、归档、恢复和删除画布。
- 支持自动布局，以及当前会话画布的选择、聚焦、适配视图、视口和工作台调整。
- 支持在用户明确要求时配置画布媒体模型范围和 ComfyUI 默认连接。
- 保留专业 Agent 的职责与权限边界，并强化取消、版本冲突和并发删除保护。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `28`。
- 提供 macOS Apple Silicon / Intel、Windows x64 和 Linux x64 安装包。
- 视图和自动布局操作需要当前会话的画布在前台可见。
- 本次保留画布 Agent 节点及已有编排数据，不进行节点移除或数据迁移。
