## 更新内容

### 移动端 Agent 与计划

- 思考、工具调用和过程文本默认收纳在可展开的“执行过程”中，最终回答单独呈现；流式思考和回答分开缓冲，减少逐 token 更新带来的界面抖动。
- Agent 与 Chat 会话支持置顶；委派子 Agent 在会话列表中按父子关系展示，并提供状态和来源信息。
- 新增移动端“计划”页，可查看自动计划、启用或暂停、立即运行，并查看最近运行记录和打开关联会话。

### 存储管理

- 按项目查看会话数量、占用空间和最近活动，并查看、排序和多选会话明细。
- 支持预览归档会话和孤儿数据后再清理；标星和置顶会话会排除在清理范围外，受管工作目录中的计划和笔记等工作台资料会保留。
- 可从会话明细打开对应工作目录；路径由主进程根据会话索引校验。

### 浏览器与下载

- 修复本地文件预览停留较久后刷新失效的问题，预览授权现在随浏览器标签生命周期管理。
- 下载、应用内更新和新版本发布配置统一指向 DutyDeck 仓库。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号递增为 `13`；提供 macOS Apple Silicon、macOS Intel、Windows x64 和 Linux x64 安装包。
- 会话、工作区、配置和 Skills 仍保存在 `~/.proma/`，本版本不迁移现有数据目录。
- 存储清理会删除所选会话历史及其可清理工作目录内容；清理前请检查预览和工作目录。归档候选默认选择，标星和置顶会话不会被纳入清理。
- macOS 安装包沿用未签名分发。若系统提示应用已损坏，确认安装包来自 DutyDeck 仓库后，将应用放入“应用程序”，再执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
