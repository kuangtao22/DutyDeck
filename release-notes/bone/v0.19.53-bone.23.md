## 更新内容

### 内置本地模型

- 在「设置 → 关于/更新 → 可选环境能力」中按需安装 llama.cpp 运行环境，再进入模型配置下载、校验、加载、测试和启用 GGUF 模型。
- 多个本地模型共享同一推理环境，运行时保持单模型加载；停止后释放运行内存并保留模型文件。
- 本地模型接入 Pi Agent；Ollama 继续作为独立外部供应商，环境与模型由 Ollama 自己管理。

### 数据目录升级

- 默认用户级数据目录改为 `~/.DutyDeck`，使用独立定位文件并只读兼容旧 Proma 定位信息；项目内的 `.proma` 不变。
- 满足旧目录身份检查时，首次启动展示可恢复迁移计划；用户继续后才复制、校验并切换，旧数据目录保留。
- 其他实例占用数据时阻止迁移；目标已有部分副本或其他文件时拒绝直接取消到新目录，保留原数据和恢复进度。

### 编排工厂与会话

- 增强失败诊断、定点补评与调用预算；成功输出可保留，补评不会改写原始实验结论或采纳资格。
- 修改现有工厂流程时优先沿用已有场景，减少误建独立场景。
- 会话运行失败后，在展开或折叠侧栏和标签页统一显示失败状态；重新运行成功后恢复正常。

### 知识库与媒体

- 完善知识提炼的暂停、继续、来源复核与内容准入，区分已生成草稿、可复用内容和已确认事实。
- 新增统一媒体 Skill，按当前可用能力选择图片、音频和视频模型，旧生图入口转入统一流程。
- 补充小说角色提取真实样本和来源验证资料；样本校验结果不代表真实模型效果提升。

### 发布修复

- 修复 macOS 打包错误：按需下载引擎不需要随包签名钩子，恢复标准签名流程。
- 调整 Windows 原生归档容量回归的总时间预算，保留完整的容量、归档与数据校验。
- 修正首次启动、再次启动及目录恢复验收脚本的默认目录，使其与 `.DutyDeck` 数据根一致。

## 升级说明

- 基于官方 `v0.19.53`，Bone 构建号为 `23`。Bone 21、22 均未完成正式 Release；本版本包含其全部变更、打包及启动验收修复。
- 首次升级前请完整退出其他 DutyDeck 实例。选择继续迁移会保留旧数据；目标尚不存在时选择取消，将使用独立空的新默认目录。
- 引擎和模型权重不随安装包预置，需用户主动下载。首期内置本地模型用于 Pi Agent，普通 Chat 与编排工厂暂不支持；Gemini 使用云端 API，本地候选包括兼容的 Qwen、Gemma GGUF 模型。
- 真实模型推理效果、硬件性能与兼容性尚未完成实机验收；本次验证覆盖配置、下载校验、生命周期及构建流程。
- 提供 macOS Apple Silicon、macOS Intel、Windows x64、Linux x64 安装包。macOS 沿用未签名分发；确认来自本仓库后，若提示应用已损坏，可将应用放入“应用程序”并执行 `xattr -dr com.apple.quarantine /Applications/DutyDeck.app`。
